# Checkpoint

- Update only current facts in `docs/PROJECT_STATE.md`.
- Include module, status, stable commit, task, done work, blockers, tests, and exact next step.
- Put detailed history in Git; do not turn the snapshot into a changelog.
- Leave the tree clean or explicitly identify intentional changes.
